## 📌 Overview
This repository contains a curated collection of Python scripts developed as part of **Harvard University's CS50P (Introduction to Programming with Python)**. 

Rather than just completing assignments, I approached these problems to build a strong foundational logic for my future academic pursuits in **Bioinformatics and Computational Biology**. The scripts demonstrate core programming competencies, including control flow, file I/O, API data extraction, and error handling.

## 🧬 Relevance to Bioinformatics
As a prospective Bioinformatics student, I utilize Python as a tool for problem-solving. The concepts practiced in this repository serve as the building blocks for computational biology:
*   **Data Extraction & Parsing:** Utilizing `requests` and `json` to fetch and format external data (similar to genomic database querying).
*   **Statistical Analysis:** Applying the `statistics` module to compute averages and limits on collected datasets.
*   **Robust Logic:** Implementing safe user inputs and `try/except` loops to ensure stable runtime environments.

## 💻 Highlighted Projects

### 1. Quote Analyzer (`random_quote.py`)
A comprehensive script that interacts with an external API (ZenQuotes).
*   **Features:** Fetches random or multiple data points, parses JSON responses, stores data in local lists, performs statistical analysis (shortest, longest, and average string length), and saves/loads the collected data locally via `.json` files.
*   **Key Modules:** `requests`, `json`, `statistics`, `sys`, `random`.

### 2. Defensive Programming & Error Handling
Scripts like `adieu.py` and `guess_the_number.py` focus on resilient code structure.
*   **Features:** Graceful handling of `EOFError` and `ValueError`, utilizing third-party libraries (like `inflect`), and designing recursive-like while loops for continuous user interaction.

### 3. String Manipulation & Control Flow
Scripts like `camel.py`, `coke.py`, and `bank.py`.
*   **Features:** Deep string formatting (converting camelCase to snake_case), state management (tracking coins inserted into a machine), and iterative condition checks.

## 🛠️ Technologies & Libraries Used
*   **Language:** Python 3
*   **Standard Libraries:** `json`, `sys`, `statistics`, `random`
*   **External Libraries:** `requests` (API integration), `inflect` (String parsing)
